# Пример заметки

Дата: 2025-10-31

## Как работать с этой системой заметок

Эта система заметок позволяет вам:

1. **Создавать заметки** - просто создайте новый .md файл в папке `notes/`
2. **Использовать Markdown** - полная поддержка форматирования
3. **Версионирование** - все изменения сохраняются в Git
4. **Синхронизация** - пушьте изменения в GitHub для бэкапа
