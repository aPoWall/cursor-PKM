# Настройка Obsidian Vault с Git и несколькими AI инструментами

## 🎯 Цель

Создать единую систему заметок Obsidian, которая:
- Хранится в Dropbox (локальный доступ и резервное копирование)
- Версионируется через Git
- Синхронизируется с GitHub
- Доступна из Obsidian, Windsurf, Cline, Claude Code одновременно

## ⚠️ Важные концепции

### Dropbox + Git = Потенциальные конфликты

**Проблема:** Dropbox синхронизирует файлы постоянно, Git тоже работает с файлами
**Решение:** Правильная настройка и четкий workflow

## 🏗️ Архитектура (2 варианта)

### ✅ Вариант 1: РЕКОМЕНДУЕМЫЙ - Git репозиторий внутри Dropbox

```
📁 Dropbox/
  └── 📁 ObsidianVault/           ← Ваш Obsidian vault
       ├── .git/                   ← Git репозиторий
       ├── .gitignore              ← Важно!
       ├── .obsidian/              ← Настройки Obsidian (игнорируются Git)
       ├── 📝 Заметки/
       ├── 📋 Проекты/
       └── 📚 Ресурсы/
```

**Преимущества:**
- ✅ Dropbox = автоматический бэкап
- ✅ Git = версионирование и синхронизация между устройствами
- ✅ Один источник истины
- ✅ Работает со всеми инструментами

**Недостатки:**
- ⚠️ Нужно быть аккуратным с коммитами
- ⚠️ Dropbox может синхронизировать .git папку (это нормально, но медленно)

### 🔄 Вариант 2: Git репозиторий вне Dropbox (сложнее)

```
📁 Dropbox/
  └── 📁 ObsidianVault/           ← Только для Obsidian

📁 ~/Projects/
  └── 📁 ObsidianVault-Git/       ← Git репозиторий
```

**Преимущества:**
- ✅ Dropbox не трогает Git
- ✅ Чистое разделение

**Недостатки:**
- ❌ Нужна ручная синхронизация
- ❌ Сложнее поддерживать
- ❌ Дублирование данных

## 🚀 Пошаговая настройка (Вариант 1)

### Шаг 1: Подготовка папки Obsidian

```bash
# Перейдите в вашу папку Obsidian в Dropbox
cd ~/Dropbox/ObsidianVault  # или ваш путь к Dropbox

# Инициализируйте Git репозиторий
git init
```

### Шаг 2: Создайте правильный .gitignore

Создайте файл `.gitignore` в корне vault:

```gitignore
# Obsidian настройки (персональные)
.obsidian/workspace.json
.obsidian/workspace-mobile.json
.obsidian/workspaces.json
.obsidian/hotkeys.json
.obsidian/app.json
.obsidian/appearance.json

# Obsidian кэш
.obsidian/cache

# Obsidian плагины (опционально - если хотите синхронизировать плагины, уберите эти строки)
# .obsidian/plugins/
# .obsidian/community-plugins.json

# Системные файлы
.DS_Store
.DS_Store?
._*
.Spotlight-V100
.Trashes
ehthumbs.db
Thumbs.db
*.tmp

# Dropbox файлы
.dropbox
.dropbox.attr
.dropbox.cache

# Конфликтные копии Dropbox
*conflicted copy*

# Временные файлы
~$*
*.swp
*.swo
*~
```

### Шаг 3: Первый коммит

```bash
# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Начальный коммит: импорт Obsidian vault"

# Создайте репозиторий на GitHub
# Перейдите на github.com и создайте новый репозиторий, например:
# Название: obsidian-vault или my-notes

# Свяжите с GitHub
git remote add origin https://github.com/ваш-username/obsidian-vault.git
git branch -M main
git push -u origin main
```

### Шаг 4: Настройка Obsidian

В Obsidian установите плагин **Obsidian Git** (рекомендуется):

1. Settings → Community plugins → Browse
2. Найдите "Obsidian Git"
3. Install → Enable

**Настройки Obsidian Git:**
```
- Auto backup: Включить
- Auto backup interval: 10 минут (или на ваше усмотрение)
- Auto pull: Включить
- Auto pull interval: 5 минут
- Commit message: "vault backup: {{date}}"
```

**Альтернатива:** Можете делать коммиты вручную через терминал или AI инструменты.

## 🛠️ Работа с разными инструментами

### 1️⃣ Obsidian (основной интерфейс)

**Использование:**
- Редактирование заметок
- Создание связей между заметками
- Визуализация графа знаний
- Использование плагинов

**Git workflow:**
- Автоматические коммиты через Obsidian Git плагин
- ИЛИ ручные коммиты через терминал
- ИЛИ попросите AI инструмент сделать коммит

### 2️⃣ Windsurf (код-редактор)

**Использование:**
- Массовое редактирование заметок
- Рефакторинг структуры
- Поиск и замена
- Работа с AI (Windsurf имеет встроенный AI)

**Как открыть:**
```bash
# Откройте папку Obsidian в Windsurf
windsurf ~/Dropbox/ObsidianVault
```

**Git workflow:**
- Используйте встроенный Git в Windsurf
- ИЛИ попросите Windsurf AI сделать коммит
- Commit → Push через UI

### 3️⃣ Cline (Claude в VS Code)

**Использование:**
- Анализ заметок
- Создание сводок
- Поиск информации
- Автоматизация задач

**Как открыть:**
```bash
# Откройте папку Obsidian в VS Code
code ~/Dropbox/ObsidianVault
```

**Работа с Cline:**
- "Найди все заметки о проекте X"
- "Создай сводку по заметкам за неделю"
- "Сохрани изменения в Git"

### 4️⃣ Claude Code (этот интерфейс)

**Использование:**
- Удаленная работа с заметками
- Автоматизация через CLI
- Скрипты и обработка данных

**Как подключить:**
```bash
# В Claude Code запустите
cd ~/Dropbox/ObsidianVault

# Или склонируйте из GitHub на другом компьютере
git clone https://github.com/ваш-username/obsidian-vault.git
```

## 🔄 Ежедневный Workflow

### Сценарий 1: Работа только с одного компьютера

```
1. Открыли Obsidian → редактируете заметку
   ↓
2. Obsidian Git автоматически делает коммит (каждые 10 мин)
   ↓
3. Переключились на Windsurf → редактируете другую заметку
   ↓
4. Git pull (автоматически в Obsidian) или вручную в Windsurf
   ↓
5. Commit → Push из Windsurf
   ↓
6. Все синхронизировано!
```

### Сценарий 2: Работа с нескольких устройств

```
Компьютер 1 (дома):
  Obsidian + Dropbox → Git push

GitHub (центральный хуб)

Компьютер 2 (работа):
  Git pull → Windsurf/Cline

Удаленный сервер:
  Claude Code → Git pull/push
```

### Сценарий 3: Конфликты (редактировали одну заметку в двух местах)

```bash
# Git сообщит о конфликте при pull
git pull

# Вариант 1: Решить через редактор
# Откройте файл с конфликтом, увидите метки:
# <<<<<<< HEAD
# Ваши изменения
# =======
# Изменения из GitHub
# >>>>>>> origin/main

# Вариант 2: Использовать AI
# "Помоги решить git конфликт в файле X"

# После решения:
git add .
git commit -m "Resolve merge conflict"
git push
```

## 🎨 Best Practices

### ✅ Делайте:

1. **Частые коммиты** - лучше 10 маленьких, чем 1 большой
2. **Понятные сообщения** - "Добавлена заметка о Python" вместо "update"
3. **Pull перед Push** - всегда получайте последние изменения
4. **Используйте .gitignore** - не храните ненужное
5. **Бэкапы** - Dropbox + GitHub = двойная защита

### ❌ Не делайте:

1. **Не редактируйте одну заметку одновременно** в разных инструментах
2. **Не забывайте пушить** - изменения должны попасть на GitHub
3. **Не игнорируйте конфликты** - решайте сразу
4. **Не храните большие файлы** в Git (>100MB) - используйте Git LFS
5. **Не паникуйте при конфликтах** - Git сохраняет обе версии

## 🚨 Решение проблем

### Проблема: Dropbox синхронизирует .git и это медленно

**Решение 1:** Ничего не делайте - это нормально, просто медленнее
**Решение 2:** Исключите `.git/` из Dropbox:
```bash
# Mac/Linux
attr -s com.dropbox.ignored -V 1 ~/Dropbox/ObsidianVault/.git

# Windows
# Правый клик на .git → Dropbox → Игнорировать
```

### Проблема: Конфликты при работе из разных мест

**Решение:**
1. Всегда делайте `git pull` перед началом работы
2. Настройте автопулл в Obsidian Git
3. Коммитьте часто
4. Используйте разные заметки в разных местах

### Проблема: Большие файлы (изображения, PDF)

**Решение:**
```bash
# Установите Git LFS
git lfs install

# Отслеживайте большие файлы
git lfs track "*.pdf"
git lfs track "*.png"
git lfs track "*.jpg"

git add .gitattributes
git commit -m "Add Git LFS"
```

### Проблема: Забыли запушить изменения

**Решение:**
```bash
# Проверьте статус
git status

# Если есть изменения
git add .
git commit -m "Forgot to push"
git push
```
