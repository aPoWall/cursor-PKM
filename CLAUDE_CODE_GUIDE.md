# Руководство по работе с Claude Code и заметками

## Что я вижу сейчас

Я создал для вас систему управления заметками (PKM - Personal Knowledge Management) со следующей структурой:

```
cursor-PKM/
├── README.md                          # Основная документация
├── CLAUDE_CODE_GUIDE.md              # Это руководство
├── .gitignore                         # Игнорируемые файлы
├── notes/                             # Папка с заметками
│   └── 2025-10-31-пример-заметки.md  # Пример заметки
└── templates/                         # Шаблоны для новых заметок
    ├── daily-note.md                  # Шаблон дневниковой заметки
    └── project-note.md                # Шаблон заметки о проекте
```

## Как сохранять заметки в GitHub

### Метод 1: Попросить Claude Code сделать коммит

Просто скажите мне:
- "Сохрани эти заметки в GitHub"
- "Закоммить и запушить изменения"
- "Сделай коммит с сообщением 'Добавлены новые заметки'"

И я автоматически:
1. Добавлю файлы в Git (git add)
2. Создам коммит с описательным сообщением
3. Отправлю изменения в GitHub (git push)

### Метод 2: Вручную через терминал

```bash
# Добавить все новые заметки
git add notes/

# Создать коммит
git commit -m "Добавлены заметки от 31 октября"

# Отправить в GitHub
git push -u origin claude/test-github-notes-integration-011CUf9KNnxHawgkE2DddWct
```

## Как работать с заметками через Claude Code

### 1. Создание новой заметки

**Скажите мне:**
- "Создай заметку о [тема]"
- "Создай ежедневную заметку"
- "Создай заметку по шаблону daily-note"

**Пример:**
```
Создай заметку о изучении Python
```

Я создам файл `notes/2025-10-31-изучение-python.md` с нужной структурой.

### 2. Редактирование заметок

**Скажите мне:**
- "Добавь в заметку [название] следующий текст..."
- "Обнови заметку [название]"
- "Найди заметку о [тема] и добавь туда..."

### 3. Поиск в заметках

**Скажите мне:**
- "Найди все заметки о Python"
- "Покажи заметки за октябрь"
- "Найди заметки с тегом #работа"

### 4. Организация заметок

**Скажите мне:**
- "Создай папку для заметок о проектах"
- "Организуй заметки по темам"
- "Создай индекс всех заметок"

### 5. Автоматическое сохранение

**Скажите мне:**
- "Создай заметку и сохрани в GitHub"
- "Обнови заметку и запуши изменения"

## Преимущества этой системы

✅ **Версионирование** - История всех изменений в Git

✅ **Поиск** - Полнотекстовый поиск через Claude Code
✅ **Автоматизация** - Claude Code помогает с рутиной
