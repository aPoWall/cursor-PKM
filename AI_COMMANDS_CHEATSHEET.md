# Шпаргалка по командам для AI инструментов

Используйте эти команды в **Claude Code**, **Cline** (VS Code), **Windsurf** и других AI помощниках.

## 📝 Создание заметок

### Базовые команды

```
Создай заметку о Python
Создай ежедневную заметку на сегодня
Создай заметку по проекту "Веб-сайт"
Создай заметку "Мои идеи" с разделами: Работа, Личное, Обучение
```

### С конкретным содержимым

```
Создай заметку "Изучение Docker" со следующим содержимым:
- Основные команды
- Best practices
- Примеры использования
```

### Из шаблонов

```
Создай заметку используя шаблон daily-note
Создай заметку о проекте используя шаблон project-note
```

## ✏️ Редактирование заметок

```
Добавь в заметку "Проекты" новый проект X
Обнови заметку "TODO" - добавь задачу "Написать отчет"
Отметь задачу "Написать отчет" как выполненную
Добавь тег #важное в заметку "Встреча"
Добавь раздел "Ресурсы" в заметку "Python"
```

## 🔍 Поиск в заметках

### Поиск по содержимому

```
Найди все заметки о Python
Найди заметки содержащие слово "проект"
Покажи все заметки с тегом #работа
Найди заметки созданные на этой неделе
Найди все незавершенные задачи
```

### Поиск и анализ

```
Найди все заметки о программировании и создай сводку
Покажи статистику по моим заметкам
Какие темы встречаются чаще всего?
Покажи все проекты в статусе "В работе"
```

## 📊 Организация и структура

```
Создай индекс всех заметок
Организуй заметки по папкам: Работа, Личное, Обучение
Создай папку "Проекты" и перенеси туда соответствующие заметки
Покажи структуру моего vault
Найди дубликаты заметок
```

## 💾 Git и синхронизация

### Базовые операции

```
Сохрани изменения в GitHub
Сделай коммит и пуш
Проверь статус репозитория
Покажи последние коммиты
Получи обновления с GitHub
```

### С описанием

```
Сохрани изменения с сообщением "Добавлены заметки о Python"
Закоммить все изменения как "Еженедельное обновление"
Синхронизируй с GitHub
```

### Проверка и история

```
Покажи что изменилось с последнего коммита
Покажи историю изменений файла "Проекты.md"
Верни заметку "Важное" к версии от вчера
Покажи разницу между текущей и прошлой версией
```

## 📈 Анализ и отчеты

### Сводки

```
Создай сводку по заметкам за эту неделю
Создай отчет по всем проектам
Сколько заметок я создал в этом месяце?
Покажи прогресс по целям
```

### Списки задач

```
Покажи все незакрытые задачи
Создай список задач на сегодня из всех заметок
Какие задачи у меня на этой неделе?
Покажи просроченные задачи
```

### Анализ содержания

```
Какие темы я изучал больше всего?
Найди все заметки без тегов
Какие заметки давно не обновлялись?
Покажи самые длинные заметки
```

## 🔗 Связи между заметками

```
Создай карту связей для заметки "Python"
Покажи все заметки связанные с "Проект X"
Найди изолированные заметки (без ссылок)
Создай граф знаний по теме "Программирование"
```

## 🎯 Специфичные для инструмента

### Для Claude Code (CLI)

```
Запусти скрипт синхронизации заметок
Проверь валидность всех Markdown ссылок
Создай бэкап заметок
Найди заметки с битыми ссылками
```

### Для Windsurf / Cline (Visual)

```
Открой заметку "Проекты" в редакторе
Покажи превью заметки "Python"
Создай новую заметку и открой её
Сравни две заметки: "План A" и "План B"
```

## 🛠️ Автоматизация

### Шаблоны и повторяющиеся задачи

```
Создай шаблон для еженедельных обзоров
Автоматически создавай ежедневные заметки
Создай заметку встречи с шаблоном: дата, участники, темы, действия
```

### Обработка данных

```
Извлеки все ссылки из заметок и создай список
Создай таблицу со всеми проектами и их статусами
Экспортируй все задачи в CSV
```

## 💡 Креативное использование

```
Преобразуй мои заметки о книге в краткое резюме
Создай mindmap из заметки "Идеи проекта"
Найди связи между несвязанными заметками
Предложи темы для новых заметок на основе существующих
```

## 🔧 Техническое обслуживание

```
Проверь все заметки на орфографию

Проверь форматирование Markdown

Удали пустые заметки
```

## 🚨 Решение проблем

```

Восстанови заметку из последнего коммита
Почему моя заметка не синхронизируется?
Проверь целостность репозитория
```

## 💬 Примеры разговорных команд

Необязательно использовать точные формулировки! AI поймет естественную речь:

- "Где я писал про Docker?"
- "Что у меня в планах на завтрое?"
- "Сохрани это все и отправь на GitHub"
- "Покажи мне что я делал на прошлой неделе"
- "Создай заметку про то что мы сейчас обсуждали"

## 📌 Быстрые команды (алиасы)

Можете создать свои короткие команды:

| Короткая команда | Что делает |
|-----------------|------------|
| `sync` | Синхронизация с GitHub |
| `new` | Создать новую заметку |
| `search [текст]` | Поиск по заметкам |
| `daily` | Создать ежедневную заметку |
| `status` | Статус Git репозитория |
