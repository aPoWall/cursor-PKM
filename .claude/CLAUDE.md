# Obsidian PKM - Claude Code Context

## 🎯 Назначение этого репозитория

Это **персональная база знаний (PKM)** на основе Obsidian с интеграцией AI инструментов.

## 📁 Структура проекта

```
cursor-PKM/
├── notes/              # Основные заметки
├── templates/          # Шаблоны для новых заметок
├── scripts/            # Скрипты автоматизации
│   ├── sync-notes.sh   # Синхронизация через git
│   ├── setup-obsidian-git.sh  # Настройка git для Obsidian
│   └── export-for-claude.sh   # Экспорт для Claude Projects
├── .claude/            # Конфигурация Claude Code
└── *.md                # Документация
```

## 🔧 Основные задачи Claude Code здесь

### 1. Работа с заметками
- Создание новых заметок (использовать шаблоны из `templates/`)
- Редактирование существующих
- Поиск и анализ информации
- Создание связей между заметками через [[wiki-links]]

### 2. Организация
- Добавление тегов (#тег)
- Создание индексов
- Рефакторинг структуры

### 3. Git операции
- Коммит изменений с понятными сообщениями
- Push в GitHub для синхронизации
- Pull перед началом работы

### 4. Экспорт для мобильного доступа
- Запуск `./scripts/export-for-claude.sh` для экспорта
- Загрузка результата в Claude Projects

## 📝 Правила создания заметок

### Формат заметки:
```markdown
---
tags: [тег1, тег2]
date: YYYY-MM-DD
---

# Заголовок

## Контекст
...

## Основное содержание
...

## Связанные заметки
- [[Заметка 1]]
- [[Заметка 2]]
```

### Именование файлов:
- Ежедневные: `YYYY-MM-DD-daily.md`
- Проекты: `проект-название.md`
- Темы: `тема-название.md`

## 🔄 Workflow синхронизации

```
1. Pull последние изменения: git pull
2. Работа с заметками
3. Коммит: git add . && git commit -m "описание"
4. Push: git push
5. (опционально) Экспорт для Claude Projects
```

## 💡 Полезные команды

### Для пользователя:
- "Создай заметку о [тема]"
- "Найди заметки с тегом #[тег]"
- "Сделай сводку по [тема]"
- "Сохрани в GitHub"
- "Экспортируй для мобильного"

### Git shortcuts:
- Статус: `git status`
- Сохранить всё: `git add . && git commit -m "update" && git push`
- Получить изменения: `git pull`

## ⚠️ Важно

- **Всегда делай git pull** перед началом работы
- **Используй шаблоны** для новых заметок
- **Не забывай пушить** после работы
- **Markdown формат** для всех заметок

## 📱 Мобильный доступ

Для доступа с мобильного устройства:
1. Запусти `./scripts/export-for-claude.sh`
2. Загрузи `_claude_export.md` в Claude Project
3. Используй Claude app для работы с контекстом

Подробнее: см. `MOBILE_SYNC_GUIDE.md`
