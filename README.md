# Cursor PKM - Personal Knowledge Management

Система управления персональными заметками с интеграцией GitHub.

## Структура проекта

```
cursor-PKM/
├── notes/          # Ваши заметки в Markdown
├── templates/      # Шаблоны для заметок
├── assets/         # Изображения и другие файлы
└── README.md       # Этот файл
```

## Как работать с заметками

### 1. Создание новой заметки

Создайте файл в папке `notes/` с расширением `.md`:
```bash
notes/2025-10-31-моя-заметка.md
```

### 2. Сохранение заметок в GitHub

Используйте стандартный git workflow:
```bash
git add notes/
git commit -m "Добавлена новая заметка"
git push
```

### 3. Работа с Claude Code

Claude Code может помочь вам:
- Создавать и редактировать заметки
- Организовывать структуру заметок
- Искать информацию в заметках
- Автоматически коммитить изменения

### 4. Шаблоны заметок

Используйте шаблоны из папки `templates/` для быстрого создания заметок.

## Возможности

- ✅ Версионирование через Git

- ✅ История изменений
